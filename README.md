# Noah Studio — Portfolio créatif

Une première version de portfolio responsive, réalisée en HTML, CSS et JavaScript sans framework.

## Prévisualiser sur ton ordinateur
1. Décompresse `noah-studio.zip`.
2. Ouvre le dossier `noah-studio`.
3. Double-clique sur `index.html` pour l'ouvrir dans ton navigateur.

Une connexion internet est nécessaire pour charger les polices Google Fonts ; le site reste utilisable sans elles.

## Personnalisation avant publication
- Dans `index.html`, remplace `tonmail@example.com` par ton adresse e-mail.
- Remplace les projets de démonstration par tes vraies réalisations, descriptions et liens.
- Les visuels de projets actuels sont des compositions CSS originales et abstraites : ils servent de placeholders, pas de preuve de travaux réels.
- Modifie le texte « À propos » pour refléter ton parcours et tes outils.
- Le nom « Noah Studio » est provisoire et peut être changé.

## Publier gratuitement avec GitHub Pages
1. Crée ou connecte-toi à un compte sur https://github.com/
2. Crée un nouveau dépôt public, par exemple `noah-studio`.
3. Envoie les fichiers `index.html`, `style.css`, `script.js` et `README.md` à la racine du dépôt.
4. Dans le dépôt, ouvre **Settings → Pages**.
5. Sous **Build and deployment**, choisis **Deploy from a branch**, sélectionne `main` et `/ (root)`, puis enregistre.
6. Après quelques minutes, ton site sera accessible à l'adresse `https://TON-PSEUDO.github.io/noah-studio/`.

Le nom exact de l'adresse dépend de ton pseudo GitHub et du nom du dépôt. Aucun achat de domaine n'est nécessaire.
